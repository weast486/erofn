# 신고가 돌파 전략 — 백테스트 매매내역 (2024-01 ~ 2026-09-23)

실전 봇의 기본 전략(`STRATEGY=breakout`)을 과거 데이터에 적용한 전체 매매 기록입니다.
전략을 고칠 때 이 기록을 기준점으로 비교하세요.

| 파일 | 내용 |
|---|---|
| `매매내역_신고가돌파.xlsx` | 안내 · 연도별요약 · 월별 · 조건별분석 · 거래내역 · 놓친신호 (요약 시트는 거래내역을 참조하는 수식) |
| `거래내역.csv` | 실제 매매 895건 (엑셀 `거래내역` 시트와 같은 내용) |
| `놓친신호.csv` | 조건은 맞았지만 10자리가 차서 못 산 신호 909건과, 샀다면 어땠을지 |

다시 만들기: `python scripts/make_breakout_report.py` (백테스트 데이터 `data/ohlcv` 필요, 루트 README의 백테스트 절 참고)

## 전략 규칙
- **매수**: 종가 기준 20일 신고가 + 한 달(20거래일) 내 첫 신고가 + 당일 거래대금 200억 이상 + 20일 평균 거래대금 30억 이상 + 10만원 이하 + 상한가 마감 제외 → 신고가 날 종가에 매수 (실전 15:10~15:20). 신호가 많으면 당일 거래대금 큰 순, 최대 10종목 × 10만원
- **매도**: 손절 -4.7% / 익절 +20%, 보유기간 제한·시장 필터 없음
- **비용**: 수수료 0.015%, 매도세 2024 0.18% · 2025 0.15% · 2026 0.20%(가정), 슬리피지 0.1%

## 조건별 분석 요약 (청산된 거래 기준)
**3년 모두 같은 방향**으로 나온 항목입니다. 한 해만 좋은 항목보다 전략 수정 근거로 믿을 만합니다.

| 항목 | 구간 | 건수 | 승률 | 손익 | 2024 / 2025 / 2026 |
|---|---|---|---|---|---|
| 20일 돌파폭 | **+2% 미만** (살짝 넘은 신고가) | 246 | 28% | +378,817원 | + / + / + |
| 당일 상승률 | **+3% 미만** | 96 | 32% | +213,936원 | + / + / + |
| 당일 거래대금 | **300억 미만** | 123 | 30% | +250,202원 | + / + / + |
| 당일 거래대금 | **2,000억 이상** | 128 | 16% | -143,346원 | - / - / - |

**2개 연도에서 같은 방향**
- 당일 상승률 **+15% 이상**: 194건, 3년 합 -122,920원 (2024·2026 손실)
- 20일 돌파폭 **+5~10%**: 222건, 승률 17%, -130,359원 (2024·2026 손실)
- 코스피 **5일 하락** 흐름에서 매수: 343건, 승률 20%, -7,409원 (2024·2026 손실, 2025 이익)
- **화요일** 매수: 174건, 승률 19%, -23,769원 (2024·2026 손실)

**기타**
- 손절된 661건 중 110건(17%)은 손절 전에 +10% 이상 올랐습니다. 익절을 낮추거나 수익 보호 규칙을 두는 아이디어의 근거가 될 수 있습니다.
- 놓친 신호 909건의 가정 결과는 승률 19.8%, -207,543원입니다. 거래대금 큰 순으로 고른 실제 매매(23.7%)가 더 나았습니다.

### 수정 아이디어 (검증 필요)
위 결과를 보면 **"크게 오른 날보다 조용히 신고가를 넘은 날"이 더 좋았습니다.** 예를 들어 돌파폭 5% 미만, 당일 상승률 15% 미만, 거래대금 2,000억 미만으로 제한하는 규칙을 시험해 볼 수 있습니다. 다만 같은 데이터에서 찾은 규칙을 같은 데이터로 확인하면 좋게 나오기 마련입니다. 적용한다면 **모의 매매로 새 기간의 결과를 먼저 확인**하세요.

## 한계
- 일봉 백테스트입니다. 신고가 판정과 매수는 종가 기준이고, 실전은 15:10~15:20 현재가로 판단합니다.
- 같은 날 손절가·익절가에 모두 닿으면 손절로 가정했습니다(보수적).
- 실전 봇은 랭킹 상위(거래대금·상승률 각 100위)에서 후보를 찾고, 백테스트는 전 종목을 봅니다.
- 과거 성과는 미래 수익을 보장하지 않습니다.
