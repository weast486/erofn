# tossbot — 토스증권 눌림목 자동매매 봇

토스증권 Open API(v1.2: 조건주문·랭킹 포함)로 동작하는 눌림목 자동매매 시스템입니다.

| 항목 | 규칙 |
|---|---|
| 대상 | 최근 10거래일 안에 **하루 +10% 이상 급등**한 종목 |
| 매수 | 현재가가 **7일선 부근(±2%)**까지 내려오면 매수. **장중 언제든**(09:00~15:20) |
| 자금 | 종목당 10만원, 동시 보유 최대 10종목 (총 100만원) |
| 손절 | 평균 체결가 대비 **-4.7%** 도달 시 **시장가** 매도 (토스 조건주문으로 서버에 등록) |
| 익절 | 평균 체결가 대비 **+15%** 도달 시 **지정가**(+15% 가격) 매도 (토스 조건주문으로 서버에 등록) |
| 보유 기간 | 제한 없음. 손절이나 익절이 걸릴 때까지 보유합니다 |

> ⚠️ 이 봇은 투자 수익을 보장하지 않습니다. 반드시 `DRY_RUN=true`(기본값)로 충분히 검증한 뒤 실거래로 전환하세요.

## 동작 방식

### 1. 급등 종목 감시 목록 (`tossbot/selector.py`, 하루 한 번)
장 시작 후 첫 주기에 감시 목록을 만듭니다.

**후보**: 상승률 상위 랭킹(1일·1주·1개월, 각 100위, 투자유의 종목 제외)에 더해, 최근 30일 동안 감시 목록에 올랐던 종목도 넣습니다. 랭킹에서 빠진 뒤에도 눌림을 계속 추적하기 위해서입니다.

**감시 목록에 넣는 조건** (완성된 일봉 기준)
1. 최근 10거래일 안에 하루 종가 기준 **+10% 이상** 오른 날(급등일)이 있음
2. 급등분을 다 반납하지 않음: 전일 종가 > 급등 전날 종가
3. 7일선이 상승 중: 전일 7일선 ≥ 5거래일 전 7일선
4. 20일 평균 거래대금 30억원 이상
5. 코스피·코스닥 보통주이고 거래정지·정리매매가 아님

### 2. 매수 신호 (장중 매 60초)
- 실시간 7일선 = (직전 6거래일 종가 합 + **현재가**) ÷ 7 로, HTS 이동평균과 같은 방식입니다.
- 현재가가 실시간 7일선의 **±2% 안**이면 "7일선 부근 도달"로 보고 매수합니다. 현재가는 급등 전 가격보다 높아야 합니다.
- 여러 종목에서 동시에 신호가 나오면 **급등폭이 큰 종목부터** 빈 자리만큼 삽니다.
- 호가 단위에 맞춘 **시장성 지정가**(현재가 +0.5%)로 주문합니다. 수량은 `floor(100,000 / 지정가)`입니다.
- 이미 보유 중인 종목은 다시 사지 않습니다. **손절·익절로 판 종목은 5일 동안 재매수하지 않습니다**(`REBUY_COOLDOWN_DAYS`).
- 15:20부터는 종가 단일가이므로 매수하지 않습니다.

### 3. 손절·익절: 토스증권 조건주문 (`/api/v1/conditional-orders`)
매수가 체결되면 **평균 체결가를 기준으로** 조건주문 2건을 증권사 서버에 등록합니다.
서버가 가격을 감시하므로 봇이 꺼져 있어도, 다음 날 시초가에 갭하락해도 작동합니다.

| 조건주문 | 감시가 (1만원 매수 시) | 발동 시 주문 |
|---|---|---|
| 손절 (SINGLE) | 진입가 × 0.953, 호가 단위로 내림 (9,530원) | **시장가** 매도 |
| 익절 (SINGLE) | 진입가 × 1.15, 호가 단위로 올림 (11,500원) | 같은 가격에 **지정가** 매도 |

- 토스 OCO는 두 조건 모두 지정가만 지원합니다. 그래서 "손절은 시장가, 익절은 지정가"를 OCO로는 걸 수 없어 SINGLE 2건으로 나눴습니다. **한쪽이 발동되면 봇이 반대쪽을 취소합니다.**
- 익절이 발동됐는데 지정가가 체결되지 않고 가격이 다시 밀리면, 남아 있는 손절 조건주문이 작동합니다.
- 조건주문 만료일은 등록일 + 30일입니다(`CONDITIONAL_EXPIRE_DAYS`). 만료되면 봇이 자동으로 다시 겁니다.
- **봇 가격 감시(60초)는 백업**입니다. 조건주문 등록에 실패한 쪽만 봇이 직접 처리합니다.

### 4. 안전장치
- 봇은 **자신이 매수한 종목만** `state/state.json`에 기록해 관리합니다. 사용자가 직접 보유한 종목은 건드리지 않습니다.
- 상태는 파일에 저장되므로 봇을 재시작해도 이어서 동작합니다.
- 실거래(`state.json`)와 모의거래(`state.dry.json`) 상태 파일을 분리합니다.
- 모든 주문에 `clientOrderId`(멱등성 키)를 붙여, 재시도해도 중복 주문이 나가지 않습니다.

## 설치 및 실행

```bash
pip install -r requirements.txt
cp .env.example .env      # TOSS_CLIENT_ID / TOSS_CLIENT_SECRET 입력
```

**API 키 발급**: 토스증권 WTS 로그인 → 설정 → Open API에서 client_id/secret을 발급하고,
**봇을 실행할 PC/서버의 공인 IP를 허용 목록에 등록**하세요.

```bash
python -m tossbot check      # 연결·계좌·매수가능금액·오늘 개장 여부 확인
python -m tossbot select     # 급등 종목 감시 목록과 7일선 대비 괴리율, 매수 신호 확인 (주문 없음)
python -m tossbot run        # 자동매매 상주 실행 (DRY_RUN=true 면 모의 체결)
python -m tossbot status     # 보유 종목·손절/익절가·매매 이력·평균 수익률
python -m tossbot liquidate  # 비상시 조건주문 취소 후 봇 보유 종목 전량 시장가 매도
```

`run`은 계속 실행되는 프로세스입니다. 서버에서는 `nohup`, `tmux`, systemd 등으로 띄워 두세요.

```bash
nohup python -m tossbot run > /dev/null 2>&1 &
tail -f logs/tossbot.log
```

실거래 전환은 `.env`에서 `DRY_RUN=false`로 바꾸면 됩니다.

## 설정 (`.env`)
값을 바꾼 뒤 봇을 재시작하면 적용됩니다. 손절·익절 %를 바꿔도, 이미 걸려 있는 조건주문은 예전 가격 그대로입니다. 새 값은 새로 매수하는 종목부터 적용됩니다.

| 변수 | 기본값 | 설명 |
|---|---|---|
| `TOTAL_BUDGET` / `NUM_STOCKS` | 1000000 / 10 | 총 투자금 / 동시 보유 최대 종목 수 (종목당 = 총액 ÷ 종목 수) |
| `STOP_LOSS_PCT` / `TAKE_PROFIT_PCT` | 4.7 / 15 | 손절 / 익절 % |
| `USE_CONDITIONAL_ORDERS` | true | 손절·익절을 토스 조건주문으로 서버에 등록 |
| `CONDITIONAL_EXPIRE_DAYS` | 30 | 조건주문 만료일 (등록일 + N일, 만료되면 재등록) |
| `BUY_START` / `BUY_END` | 09:00 / 15:20 | 매수 가능 시간대 |
| `MONITOR_INTERVAL_SECONDS` | 60 | 7일선 도달 확인 및 손절·익절 백업 감시 주기(초) |
| `SURGE_PCT` | 10 | 급등 기준 (하루 상승률 %) |
| `SURGE_LOOKBACK_DAYS` | 10 | 최근 N거래일 안의 급등만 인정 |
| `MA_PERIOD` | 7 | 기준 이동평균 (7일선) |
| `MA_BAND_PCT` | 2 | 이평선 ±N% 안이면 "부근 도달" |
| `REQUIRE_MA_RISING` | true | 이평선이 상승 중인 종목만 |
| `MIN_AVG_TRADING_AMOUNT` | 3000000000 | 20일 평균 거래대금 하한 (30억) |
| `REBUY_COOLDOWN_DAYS` | 5 | 매도한 종목의 재매수 금지 기간(일) |

## 유의사항
- **떨어지는 칼날을 잡을 수 있습니다.** 7일선 부근은 지지선이 될 수도 있지만 이탈 직전일 수도 있습니다. 급락 중에 ±2% 구간을 지나가는 순간에 매수될 수 있으므로, 필요하면 `MA_BAND_PCT`를 줄이세요.
- **보유 기간 제한이 없습니다.** 손절(-4.7%)과 익절(+15%) 사이에서 오래 횡보하는 종목은 자리를 계속 차지합니다.
- 손절은 시장가라 확실히 팔리지만, 갭하락하면 -4.7%보다 낮은 가격에 체결될 수 있습니다.
- 급등 종목은 랭킹 API의 상승률 상위 100위(1일·1주·1개월)에서 찾습니다. 랭킹에 한 번도 오르지 않은 급등 종목은 놓칠 수 있습니다. 봇을 계속 켜 두면 매일 본 급등 종목을 30일간 기억해서 누락이 줄어듭니다.
- 조건주문 2건이 같은 수량에 동시에 걸리는지(매도 가능 수량을 묶는지)는 공개 문서로 확인되지 않았습니다. 두 번째 등록이 실패하면 그쪽은 봇 가격 감시로 대신 처리합니다. 실거래 첫날 `python -m tossbot status`로 손절·익절이 "조건주문"으로 표시되는지 확인하세요.
- 조건주문 만료일의 최대 허용 기간은 문서로 확인하지 못했습니다. 30일이 거부되면 로그에 등록 실패가 남으니 `CONDITIONAL_EXPIRE_DAYS`를 줄이세요.
- Open API의 초당 호출 한도는 공개되지 않았습니다. 429 응답을 받으면 `Retry-After`에 맞춰 자동으로 재시도합니다. 감시 목록은 하루 한 번만 만들고, 장중에는 현재가만 묶어서 조회합니다.
- 매매 비용(수수료, 매도 시 증권거래세)이 매번 발생하므로 실제 수익률은 표시된 손익률보다 낮습니다.
- 규칙은 과거 데이터로 검증하지 않았습니다. `selector.py`에서 조건을 바꿔 보세요.
