# tossbot — 토스증권 주간 자동매매 봇

토스증권 Open API(v1.2, 조건주문 포함)로 동작하는 주간 스윙 자동매매 시스템입니다.

| 항목 | 규칙 |
|---|---|
| 투자금 | 총 100만원, 10종목 × 종목당 10만원 동일비중 |
| 매수 | 매주 **화요일** 09:10(정규장 시작 10분 후), 상승 가능성이 높아 보이는 10종목 선정 후 매수 |
| 손절 | 평균 체결가 대비 **-4.5%** 도달 시 **시장가** 매도 (토스 조건주문으로 서버에 등록) |
| 익절 | 평균 체결가 대비 **+15%** 도달 시 **지정가**(+15% 가격) 매도 (토스 조건주문으로 서버에 등록) |
| 청산 | **금요일 또는 공휴일 전날 15:10**, 조건주문 취소 후 봇이 산 종목 전량 시장가 매도 |

> ⚠️ 이 봇은 투자 수익을 보장하지 않습니다. 반드시 `DRY_RUN=true`(기본값)로 몇 주간 검증한 뒤 실거래로 전환하세요.

## 동작 방식

### 1. 종목 선정 (`tossbot/selector.py`)
`universe.txt`의 종목(기본 97개 대형주)을 대상으로 **전일까지의 일봉**으로 계산합니다.

**필터** (모두 통과해야 후보)
1. 정배열: 종가 > 20일 이동평균 > 60일 이동평균
2. RSI(14)가 50~75: 상승 추세이되 과열 구간은 제외
3. 최근 5거래일 상승률 15% 이하: 이미 급등한 종목 추격 방지
4. 20일 평균 거래대금 30억원 이상: 유동성 확보
5. 1주 가격 ≤ 10만원: 종목당 예산으로 최소 1주 매수 가능
6. 상장폐지·거래정지·정리매매 종목, 우선주·ETF 제외 (`/api/v1/stocks`)

**점수**: 후보 간 백분위 순위의 가중합으로 매깁니다.
20일 수익률 40% + 거래량 증가율(5일/20일) 30% + 20일 고가 근접도 30%. 상위 10종목을 고릅니다.
조건을 통과한 종목이 10개보다 적으면 그만큼만 매수하고 나머지는 현금으로 둡니다.

### 2. 매수
- 호가 단위에 맞춘 **시장성 지정가**(현재가 +0.5%)로 주문합니다. 즉시 체결되면서도 슬리피지 상한이 있습니다.
- 수량은 `floor(100,000 / 지정가)`입니다. 예를 들어 주가 3만원이면 3주를 사서 약 9만원만 투자되며, 주가가 높을수록 남는 현금이 커집니다.
- 매수 가능 금액(`/api/v1/buying-power`)을 넘으면 주문을 멈춥니다.
- 모든 주문에 `clientOrderId`(멱등성 키)를 붙여, 네트워크 오류로 재시도해도 중복 주문이 나가지 않습니다.

### 3. 손절·익절: 토스증권 조건주문 (`/api/v1/conditional-orders`)
매수가 체결되면 **평균 체결가를 기준으로** 조건주문 2건을 증권사 서버에 등록합니다.
서버가 가격을 감시하므로 봇이 꺼져 있어도 손절·익절이 실행됩니다.

| 조건주문 | 감시가 | 발동 시 주문 |
|---|---|---|
| 손절 (SINGLE) | 진입가 × 0.955, 호가 단위로 내림 | **시장가** 매도 |
| 익절 (SINGLE) | 진입가 × 1.15, 호가 단위로 올림 | 같은 가격에 **지정가** 매도 |

- 토스 OCO는 두 조건 모두 지정가만 지원합니다. 그래서 "손절은 시장가, 익절은 지정가"를 OCO로는 걸 수 없어 SINGLE 조건주문 2건으로 나눴습니다. **한쪽이 발동되면 봇이 반대쪽을 취소합니다.**
- 익절이 발동됐는데 지정가가 체결되지 않고 가격이 다시 밀리면, 손절 조건주문이 그대로 남아 있어 손절이 작동합니다.
- 만료일은 그 주 금요일입니다. 청산 시 봇이 먼저 취소하지만, 봇이 멈춰도 다음 주로 넘어가지 않게 하는 안전장치입니다.
- **봇 가격 감시(60초)는 백업**입니다. 조건주문 등록에 실패한 쪽만 봇이 직접 처리합니다(손절은 시장가, 익절은 지정가).
- `USE_CONDITIONAL_ORDERS=false`로 두면 조건주문 없이 봇 가격 감시만 사용합니다.
- 익절 지정가가 부분 체결되면 남은 수량 기준으로 조건주문을 다시 등록합니다.

### 4. 매수일·청산일 판단 (`tossbot/market_calendar.py`)
`/api/v1/market-calendar/KR`의 이전·다음 영업일 정보로 판단하므로 공휴일 목록을 따로 관리하지 않아도 됩니다.
- **청산일**: 오늘이 개장일이고 *다음 영업일 ≠ 내일*인 날. 금요일(다음 날이 주말)과 공휴일 전날이 모두 해당합니다.
- **매수일**: 화요일. 단, 화요일이 휴장이거나 연휴 전날(청산일)이면 그 주의 다음 거래일(수·목)에 매수합니다. 청산일에는 매수하지 않습니다.
- 한 주에 한 번만 매수합니다. 손절·익절로 슬롯이 비어도 그 주에는 다시 사지 않습니다.
- **청산 (15:10)**: 손절·익절 조건주문 취소 → 대기 중인 익절 지정가 주문 취소 → 매도 가능 수량 전부 시장가 매도.
  청산 시각 이후에는 매 주기 이 과정을 반복해, 취소 처리가 늦은 잔량도 정리합니다.

### 5. 안전장치
- 봇은 **자신이 매수한 종목만** `state/state.json`에 기록해 관리합니다. 사용자가 직접 보유한 종목은 건드리지 않습니다.
- 상태는 파일에 저장되므로 봇을 재시작해도 이어서 동작합니다.
- 실거래(`state.json`)와 모의거래(`state.dry.json`) 상태 파일을 분리합니다.

## 설치 및 실행

```bash
pip install -r requirements.txt
cp .env.example .env      # TOSS_CLIENT_ID / TOSS_CLIENT_SECRET 입력
```

**API 키 발급**: 토스증권 WTS 로그인 → 설정 → Open API에서 client_id/secret을 발급하고,
**봇을 실행할 PC/서버의 공인 IP를 허용 목록에 등록**하세요. 고정 IP가 있는 집 PC, 클라우드 VM 등이 적합합니다.

```bash
python -m tossbot check      # 연결·계좌·매수가능금액·오늘 매수일/청산일 여부 확인
python -m tossbot select     # 지금 기준 선정 종목 미리보기 (주문 없음)
python -m tossbot run        # 자동매매 상주 실행 (DRY_RUN=true 면 모의 체결)
python -m tossbot status     # 봇 보유 포지션·매매 이력·평균 수익률
python -m tossbot liquidate  # 비상시 봇 보유 종목 즉시 전량 매도
```

`run`은 계속 실행되는 프로세스입니다. 서버에서는 `nohup`, `tmux`, systemd 등으로 띄워 두세요.

```bash
nohup python -m tossbot run > /dev/null 2>&1 &
tail -f logs/tossbot.log
```

실거래 전환은 `.env`에서 `DRY_RUN=false`로 바꾸면 됩니다.

## 설정 (`.env`)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `TOTAL_BUDGET` | 1000000 | 총 투자금 |
| `NUM_STOCKS` | 10 | 종목 수 (종목당 = 총액/종목 수) |
| `STOP_LOSS_PCT` / `TAKE_PROFIT_PCT` | 4.5 / 15 | 손절 / 익절 % |
| `USE_CONDITIONAL_ORDERS` | true | 손절·익절을 토스 조건주문으로 서버에 등록 |
| `BUY_DELAY_MINUTES` | 10 | 정규장 시작 후 매수까지 대기 시간(분) |
| `LIQUIDATION_TIME` | 15:10 | 금요일·공휴일 전날 전량 매도 시각 |
| `MONITOR_INTERVAL_SECONDS` | 60 | 봇 가격 감시(백업) 주기(초) |
| `MIN_AVG_TRADED_VALUE` | 3000000000 | 최소 20일 평균 거래대금 |
| `MAX_5D_RETURN_PCT` | 15 | 최근 5일 상승률 상한 |
| `UNIVERSE_FILE` | universe.txt | 선정 대상 종목 목록 |

## 유의사항
- 손절은 시장가라 확실히 팔리지만, 급락이나 갭하락이면 -4.5%보다 낮은 가격에 체결될 수 있습니다.
- 조건주문이 매도 가능 수량을 미리 묶어두는지 여부는 공개 문서로 확인되지 않았습니다. 만약 묶어둔다면 두 번째 조건주문 등록이 실패할 수 있는데, 그 경우 해당 쪽은 봇 가격 감시로 대신 처리합니다. 실거래 첫 주에 `python -m tossbot status`로 두 조건주문이 모두 걸렸는지 확인하세요.
- Open API의 초당 호출 한도는 공개되지 않았습니다. 429 응답을 받으면 `Retry-After`에 맞춰 자동으로 재시도합니다.
- 종목당 10만원이라 삼성바이오로직스처럼 1주 가격이 10만원을 넘는 종목은 매수할 수 없어 선정에서 자동으로 빠집니다.
- 매매 비용(수수료, 매도 시 증권거래세)이 매주 발생하므로 실제 수익률은 표시된 손익률보다 낮습니다.
- 선정 규칙은 단기 모멘텀 휴리스틱일 뿐입니다. `selector.py`의 필터와 가중치(`WEIGHTS`)를 자유롭게 바꿔 보세요.
